Installing

  1. I have successfully downloaded the file IASETUPFULL.EXE to my computer.  But how do I install it?

    Simply run IASETUPFULL.EXE. The installation screen will pop-up and guide you through the rest of the installation. To "run" IASETUPFULL.EXE, use your "Windows Explorer" or "File Manager" to double-click folders until you open the folder that contains IASETUPFULL.EXE. Then simply double-click on IASETUPFULL.EXE to run it. The installation screen will pop-up and guide you through the rest of the installation.

  2. I can't find the file on my computer. I think I successfully downloaded it, but I don't know where it is. How can I find it?

    Windows 95/98 Users:
    Click the "Start" button, point to "Find," and then click "Files or Folders." In the "Named" box, type the file's name (for example, IASETUPFULL.EXE ). Click "Find Now" to find the file. Then simply double-click on the file to run it. The installation screen will pop-up and guide you through the rest of the installation.

  3. When I try to install the program, I get the error "corrupt installation file" or "Win32"?

    The error "corrupt installation file" or "Win32" is usually caused by an incomplete download. What sometimes happens when there is a slow download is that your computer thinks the download is done because it hasn't received any new information for a while. In fact it isn't, but since you don't have the entire program, when you try to run it, it will fail with the above error. The solution is to delete the incomplete or corrupt file and then download the program again.

  4. When I try to run the installation for InternetALERT I get an error message that says, "GLBSSTUB caused an invalid page fault in module KRNL386.dll."

This error message is being experienced on some customers' computers if they are using an Asian-language version of Windows on their system.  We do not currently have a fix for this problem and we sincerely apologize if you are getting this error.  Please use the contact information on the Invoice Summary we asked you to print out after your purchase to notify us that you have had this problem or contact Customer Support.
