Installing

  1. I have successfully downloaded the file BB4SETUP.EXE to my computer.  But how do I install it?

    Simply run BB4SETUP.EXE by double clicking on it with your left mouse button. The installation screen will pop-up and guide you through the rest of the installation. To "run" BB4SETUP.EXE, use your "Windows Explorer" or "File Manager" to double-click folders until you open the folder that contains BB4SETUP.EXE. Then simply double-click on BB4SETUP.EXE to run it. The installation screen will pop-up and guide you through the rest of the installation.

  2. I can't find the file on my computer. I think I successfully downloaded it, but I don't know where it is. How can I find it?

    Click the "Start" button, point to "Find" or "Search," and then click "Files or Folders." In the "Named" box, type the file's name (for example, BB4SETUP.EXE ). In the "Look In" field, choose either "My Computer" or your "C: Drive."  Click "Find Now" to find the file. Then simply double-click on the file to run it. The installation screen will pop-up and guide you through the rest of the installation.

  3. When I try to install the program, I get the error "corrupt installation file" or "Win32"?

    The error "corrupt installation file" or "Win32" is usually caused by an incomplete download. What sometimes happens when there is a slow download is that your computer thinks the download is done because it hasn't received any new information for a while. In fact it isn't, but since you don't have the entire program, when you try to run it, it will fail with the above error. The solution is to delete the incomplete or corrupt file and then download the program again.
