BonziBUDDY™ Talking Module

The BonziBUDDY Talking Module, when properly installed and set up, will allow you to speak commands to Bonzi, answer his questions, and interact with him in different ways.  Ask Bonzi how he's doing today, and he'll reply to you as only an Internet traveling companion can!  The Talking Module is the most popular add-on module that we have created for BonziBUDDY.

 

How does the Talking Module work?

The Talking Module uses Microsoft's Speech Recognition Engine version 4.0 to train Bonzi how to understand your voice.  After installing the Talking Module you will be walked through setting up your microphone and reading several paragraphs of text to teach the speech engine how to understand your specific voice patterns.  The more training that you do, the better the speech engine works.  Once the speech engine is trained, it's as easy as holding down your Scroll Lock key on your keyboard until you see a small window pop up under Bonzi that says "Bonzi is listening."  Once you see this message, speak the pre-set list of commands that BonziBUDDY can understand, and Bonzi will understand what you have asked him to do.

 

Does the BonziBUDDY™ Talking Module have any special requirements?

This module will work with most current versions of Windows (95, 98, ME, NT, 2000, and XP).  To get it working on Windows XP takes a little extra effort due to some upgrades that Microsoft made to the speech recognition components in XP, but once those issues are ironed out, Windows XP should work as good as, if not better than any of the other versions of Windows when it comes to talking to your BonziBUDDY.  The Talking Module also requires that you have a sound card on your computer that contains a microphone input jack (almost all computers have this installed before you buy them) and a good microphone to plug into that jack.  Close-talk microphone headsets work the best (the ones with a foam ball over the microphone that sits just under your mouth, close to your chin), but small boom-type microphones that sit on your desk and point up toward your mouth should work as well.  Microphones that are connected to the computer or to the monitor will not work as well, but might be sufficient.

 

Is the Talking Module compatible with America Online (AOL)?

Absolutely!  The Talking Module will work with any ISP (Internet Service Provider) because it is one of the very few modules for BonziBUDDY that do not rely on your Internet connection.  The Talking Module will work just as well when you are NOT connected to the Internet, as it does when you are connected to the Internet.  Note, however, that some of the commands that you can speak to your BonziBUDDY (such as asking him to Search or Browse the Internet) will require that your Internet connection is open.

 

How do I set up the Talking Module?

The first step to setting up the Talking Module is to download an update to Windows XP.  The reason for this is that, when Microsoft developed Windows XP, they upgraded the software within Windows that controls speech recognition.  By doing this, they effectively made their own Microsoft Speech Recognition Engine (which BonziBUDDY uses) incompatible with Windows XP because of the underlying software that controls it, which is called SAPI 5.0.    SAPI stands for Speech API.  In order to use BonziBUDDY's Talking Module you must have SAPI version 4.0 installed on your computer.  The good news is that SAPI 4.0 and SAPI 5.0 can both coexist on your Windows XP computer without affecting the operation of the other!  That means that we can fix this problem!

So, our first step is to install SAPI 4.0 on your Windows XP computer.  To do so, open your web browser (if you're reading this, you already have it open).  Let's open a new window so that we don't have to leave this page.  Just go up to the toolbar above this page, select File > New > Window.  This page should open up in a brand new browser window.  Once it is open, type the following into the Address bar at the top of the window (or click on this highlighted blue link) to start the download:  http://download.bonzi.com/spchapi

If you type the address into the Address bar, it should look like this:

 

Once you have the address typed in, click on the GO button and you will be asked if you want to Open the file or Save the file, as shown here:

At this point, if you are comfortable with downloading files to a folder on your computer and later finding them and double-clicking to open them, go ahead and do so.  If you are NOT comfortable with this process, choose to Open the file.  Once you choose to Open the file, it will start downloading to your computer.  Make sure that you leave your Internet Connection open until the file is fully downloaded and the installation of the SAPI 4.0 software is complete.

Once the installation is complete, you can disconnect your Internet connection if you desire to do so, but it is not necessary.  Once this version of SAPI is installed, you will have a new item in your control panel that we will talk about a little further on in this guide.

We're now ready to install the Talking Module!

Now that we have the necessary speech software on our computer to run the Talking Module, let's install the module itself.  If you're reading this you are either a BonziBUDDY Gold Member or you have received an e-mail from us that has a web page address and an access code number on it.  Depending on which of these fits your situation, you now need to follow the instructions that you have been given.

GOLD MEMBERS: right-click on your BonziBUDDY and choose Gold Member Access.  Highlight Talking Module in the list and click the Add button to transfer Talking Module to the list on the right side of the screen.  When it is on the right, click on the Install Now button to install the Talking Module.

NON-GOLD MEMBERS and ACCESS CODE users:  at this time, go ahead and follow the instructions you were given to download the program.  When you're finished with your download, return to this page to make sure that you have completed the Talking Module Setup!  If you need an access code, send an e-mail to your Talking Module customer number @bonzi.com.  This will automatically send you back an access code to use for the download!

Now we're ready to setup the microphone and train the speech engine to know your voice!

Once the Talking Module is installed, BonziBUDDY will break into a long speech about the module and how to use it.  He should also walk you through the settings for your microphone and the voice training.  If he has already done this, you can skip to the "Operating the Talking Module" section below.  If he didn't, or if you need to train the speech engine again, keep reading below.

Operating the Talking Module

Now that you've been through the training for Bonzi's Talking Module, you are ready to use it!  To put Bonzi in "listening mode" all you need to do is hold down your Scroll Lock key for a few seconds until you see a small box pop up under Bonzi that says, "Bonzi is listening."  Once you see this small box, you can speak a command to Bonzi!

To see the list of commands that you can speak to Bonzi, right click on him and choose "My Voice Commands."  When you do so, the voice commands window will open and show you the words that you can speak to Bonzi:

You can also answer "Yes" or "No" to the questions that Bonzi asks you about other products and services to reply to what he is asking.  That is about all there is to the Talking Module for BonziBUDDY!
