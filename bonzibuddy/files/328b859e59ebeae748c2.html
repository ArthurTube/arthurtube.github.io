Why Should I Worry About Memory Leaks?

Memory leaks waste space by filling up pages of memory with inaccessible data. Memory leaks waste time by causing unnecessary paging activity. But more importantly, data loss and file damage can result from Windows crashes and "blue screens of death."

Memory leaks are the cumulative deterioration of your computer's performance that occurs over time as the result of fragmentation of your computer's RAM (Random Access Memory) as programs fail to free up blocks of memory that are no longer needed.

The resulting consequences can be serious because leaking applications slow down over time and eventually your whole system reacts in a sluggish manner. That's when your applications–and even your operating system–crash.

Programs also sometimes end unexpectedly or crash before they can shut down in an orderly fashion and give back their memory. The result is that blocks of memory scattered throughout your system's RAM are marked as "in use." Over time, more and more memory leaks into this unusable state until eventually Windows finds that there's not enough memory to operate.

Then Windows displays an error message saying memory is low and requests that some applications be closed to free up space. But because the applications that locked up the memory aren't really running, you can't free up the space by closing them down. The only solution is the time-consuming process of rebooting your computer, re-opening all your applications and data files -- and hoping that the access errors did not cause any data corruption or data loss of whatever you were working on before the crash.
