BonziBUDDY� Download Manager Help Page

 

Want to learn more about using the BonziBUDDY� Download Manager?  Please visit the Download Manager User's Guide.

Can't find your answer? Please contact Customer Support!

 

Does Your Question Involve:

  1. How do I use the Download Manager?
  2. My download failed and I have already entered my payment information.  I have already purchased the Download Manager and need to download it again.
  3. I get an error that says, "Cannot add.  An entry already exists in the list with the same URL (Download Site)."
  4. My Download Manager isn't working.
  5. I uninstalled BonziBUDDY and the Download Manager and am receiving the following error message: "Failed to Create ObjDM."
  6. Every time BonziBUDDY opens up, he tells me that there is a file (or files) that we have not yet downloaded.  How do I stop BonziBUDDY from saying this every time he comes up?

 

Answers:

  1. How do I use the Download Manager?

The great thing about our new Download Manager is that you don't have to do much of anything!  Any time you download a file from the Internet, the BonziBUDDY Download Manager will automatically kick in to take control of your download for you.  Just go about your business handling Email or visiting web pages while BonziBUDDY makes sure that your download continues.  If the Download Manager is not starting automatically when you download a file, right-click on Bonzi, go to Download Files, and click on the Options button.  Make sure that the check mark is on for "Integrate Download Manager with Internet Explorer."

  1. My download failed and I did not get my product.

Sometimes downloads fail; we just have to live with that as one of the nuances of the Internet.  If your download attempt did not complete successfully, please visit our Email Request page to get another copy.  You will need your credit card number.

You can also send an email to your customer number @bonzi.com.  For instance, if your customer number is 1234567, just send an email to 1234567@bonzi.com and we will send you the information that you need to download the file again without another charge.

  1. I get an error that says, "Cannot add.  An entry already exists in the list with the same URL (Download Site)."

This just means that the download file you are trying to receive is already listed in the Download Manager window.  Just right-click on BonziBUDDY and choose Download Manager.  In the file list, find the file you are trying to download, highlight it, and click the Download button.  BonziBUDDY will monitor the download for you!

  1. My Download Manager isn't working.

There are two possibilities: either the Download Manager is disabled or you are not using Version 5.0 of Internet Explorer.  If you aren't using at least version 5.0, please go to http://www.microsoft.com/ie and download the newest version. To check your version, in Internet Explorer go to the Help menu and choose About Internet Explorer.

If you already have version 5.0 or higher, then check this:  Right click on Bonzi and choose Download Files, then go to the Options, and check the box that says "Integrate the Download Manager with Internet Explorer."  This will make it so that any file you click to download in Internet Explorer will open the Download Manager.

You might want to check out our online user guide at http://www.bonzi.com/support/DMGuide.htm for a description of each of the Download Manager�s features. 

BonziBuddy notifies you that there are items waiting to be downloaded if he has not downloaded them yet.  He also notifies you that you need to install, or "run," them if you have not done so already.  If he tells you that he cannot locate the file, there are only two possibilities:  the file is not located where the URL is pointing to (AKA it is a bad link) or you are not currently connected to the Internet and he has no way to connect with the server that is hosting the file.  If you're sure that you're connected to the Internet, just highlight the link and remove it from the list since it isn't working.

  1. I uninstalled BonziBUDDY and the Download Manager and am receiving the following error message: "Failed to Create ObjDM" after uninstalling BonziBUDDY.

    This error is caused when a file failed to remove itself during the BonziBUDDY uninstall process. To fix, first Close any open Internet Explorer, AOL, or other web browser windows that you have running.  Then,     open the 'My Computer' > C: Drive > 'Windows' > 'System' folder and look for two files named IEHelperMiddleMan. When you find these two files, delete them, and you will no longer get this error.  If Windows displays a message indicating that the files are in use and cannot be deleted, then complete the following 6 steps for removal:

    Steps to Uninstall and Remove IEHelperMiddleMan Files

    Step 1: Shut down or close any applications that you have running (most importantly, close all open Internet Explorer browser windows).
    Step 2: Click 'Start' button in Windows, then click 'Run'.
    Step 3: Type in the following command, exactly as it appears below, into the Run dialog window and click OK:

    regsvr32 /u iehelpermiddleman.dll
    Step 4: Windows will remove registry entries associated with IEHelperMiddleMan and will then display the message, "DLLUnregisterServer in iehelpermiddleman.dll succeeded".  Click OK on this message.
    Step 5: Reboot your computer.  You should no longer receive the "Failed to Create ObjDM" error message.
    Step 6: If you like, after rebooting, you may safely delete the two IEHelperMiddleMan files from your System or System32 folder, as they are only required for the BonziBUDDY Download Manager.

    If you still receive this error after completing the above steps, please contact technical support.

  2. Every time BonziBUDDY opens up, he tells me that there is a file (or files) that we have not yet downloaded.  How do I stop BonziBUDDY from saying this every time he comes up?

    This message means that there is a file listed in your BonziBUDDY Download Manager that has not yet been fully downloaded to your computer.  There are two things that you can do to fix this.  First, you could open the download manager, select the file, and download it.  Once it is downloaded, Bonzi will no longer notify you that the file is listed.  You can also just remove the file from the Download Manager window to get Bonzi to stop notifying you.  Just highlight the file and choose Remove.  Don't confuse this with the Delete function, which is used to delete files that have already been downloaded from your hard drive.
