ARTHUR TUBE — CYBERBUDDY MUSEUM AND PROXY WEBSITE

Extract this ZIP. Upload the folders into the root of your arthurtube.github.io repository, keeping their folder structure. Do not upload the ZIP itself. Keep your existing homepage index.html. ADD_TO_INDEX.html contains navigation to paste into that homepage.

Open cyberbuddy-museum/index.html for the original CyberBuddy website museum.
Open cyberbuddy/index.html for the Classic Proxy pages.
Open cyberbuddy-continuation/index.html for Arthur Tube's unofficial continuation.
Open weather/forecast.html for the uploaded proxy's forecast layout.

Museum: 243 original files downloaded from thecyberbuddy.com on October 11, 2026. 4 requested files failed. Unavailable local links point to the original website. The original layout, images and credits are retained where downloaded; a museum notice was added and old scripts/tracking removed. This is a bounded museum copy, not a complete backup of every server file. download-report.json records the download results. Historical download links may be unavailable; original installers are not bundled.

News uses the uploaded proxy's rendering method and a dated 20-headline snapshot, not live browser news. Jokes and thoughts use 1,232 entries from its source. Email requires the local proxy's POP3/SMTP service; no website password form is provided. Chat remains experimental. This package does not run the Python proxy on GitHub Pages.

Weather uses browser requests to Open-Meteo, subject to service availability. Historical weather archive pages are separate from live forecasts. Not every original weather archive page was available in the upload.

Original CyberBuddy: John M. DeFino. Independent continuation and compatibility project: Arthur Tube. No native EXE bug fix or deployment is claimed. Download/path checks passed; Windows client behavior and browser appearance remain unverified.
