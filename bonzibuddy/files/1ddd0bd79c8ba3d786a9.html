Q&A Section

Downloading

  1. My download was unsuccessful. My Internet provider cut me off. I do not have my software yet. What do I do now?

    Please download a new copy by going to the "BONZI.COM" web site.

  2. I lost my original download. How can I get a replacement copy?

    You can download a new copy of the FREE BonziBUDDY by going to http://www.bonzi.com web site.

  3. Do I download to my diskette drive or my hard drive?

    You must download to your hard drive. The download will not work if you are trying to download to diskette.

  4. While I am downloading BonziBUDDY, it tells me to insert Disk 2?

    Please make sure to download the program to your hard drive. Please click here to complete your download of BonziBUDDY.

  5. I connect to the Internet through a Proxy Server and I can't download BonziBUDDY.  What should I do?

    Unfortunately at this time you will not be able to install BonziBUDDY.  We plan on finding a way to make the BonziBUDDY installation work through a proxy server or firewall in the near future, but at this time we do not have a solution.  Keep an eye on this page to find out when that changes.

  6. I get an SSA3D30 error message when I try to install BonziBUDDY or an add-on module.

This error is caused by a discrepancy between an old version of the installation software and the new one.  If you try to install anything using the new version when you have not updated your BonziBUDDY, you will get this error.  To fix this, simply run the FREE BonziBUDDY install again.
