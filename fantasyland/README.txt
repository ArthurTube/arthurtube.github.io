FILTER FANTASYLAND FOR ARTHURTUBE GITHUB PAGES

Upload this entire "fantasyland" folder to the root of the arthurtube.github.io repository.
The resulting address will be:
  https://arthurtube.github.io/fantasyland/

This package intentionally leaves your existing root index.html untouched.

IMPORTANT
This build hosts a full-page launcher/embed of the currently public Filter Fantasyland app.
It does NOT claim to contain the site's missing/private source modules. This preserves the
working live editor behavior for visitors instead of substituting reconstructed controls.

If the source site blocks iframe embedding in the future, visitors can use the included
"open Filter Fantasyland" fallback link.
