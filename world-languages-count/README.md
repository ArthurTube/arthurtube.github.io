# ArthurTube — World Languages Timeline

Static GitHub Pages site: `world-languages-count/index.html`

## Scope

- 10,000 BC to AD 3000, including **before 3100 BC** and every individual calendar year (no year zero).
- Before 3100 BC: prehistoric speech with unknown language names and counts. No invented attestations.
- Historical first written attestations: user-supplied `List of languages by first written account`. Approximate dates remain approximate.
- AD 1000: historical written attestations, not a future simulation.
- AD 2027–3000: fictional future language stages, clearly labeled.
- Multiple charts, language catalog, text tester and exports.

The cumulative historical chart counts *entries first documented in the supplied source*, not total spoken languages.

Upload the `world-languages-count` directory to the root of the `arthurtube.github.io` repository.
