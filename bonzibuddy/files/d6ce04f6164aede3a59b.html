Installing

  1. I have successfully downloaded the file BB1SETUP.EXE to my computer.  But how do I install it?

    Simply run BB1SETUP.EXE by double-clicking on the file icon. Open My Computer > C: Drive and keep opening folders to get to the folder where you saved the file.  Once you double click on the file, the installation screen will pop-up and guide you through the rest of the installation.

  1. I can't find the file on my computer. I think I successfully downloaded it, but I don't know where it is. How can I find it?

Click the "Start" button, point to "Find," and then click "Files or Folders." In the "Named" box, type the file's name (for example, BB1SETUP.EXE ). Click "Find Now" to find the file. Then simply double-click on the file to run it. The installation screen will pop-up and guide you through the rest of the installation.

  1. When I try to install the Talking Add-on, it tells me to insert Disk 2.

This message is usually caused by an incomplete or corrupt download. The solution is to download the program again. Please fill in the "E-Mail Request Form."  We will verify your purchase and send the download instructions directly to your e-mail.

  1. When I try to install the program, I get the error "corrupt installation file" or "Win32"?

The error "corrupt installation file" or "Win32" is usually caused by an incomplete download. What sometimes happens when there is a slow download is that your computer thinks the download is done because it hasn't received any new information for a while. In fact it isn't, but since you don't have the entire program, when you try to run it, it will fail with the above error. The solution is to delete the incomplete or corrupt file and then download the program again.
