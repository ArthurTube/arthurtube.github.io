Voice E-Mail Error Messages:

  1. 35163 or 20162.

    Please add less-than "<"   and greater-than ">" symbols to the front and back of the email address in your "Address" box. For example: <example@aol.com>.

    If you don't have the most recent version, please  Click here.  This will take you to the updates page.

  2. 25061 or 25048.

    Please make sure you have the latest version of Voice E-Mail.  The latest version is 4.0.9, Build #8 created on 5/18/99.   To check your version, please double click on the Voice E-Mail icon on your desktop, click help and then about.  Toward the middle it should indicate the version and build number.

    If you don't have the most recent version, please  Click here.  This will take you to the updates page.

  3. 25052.

    Please verify that your email address is entered correctly in your Voice E-Mail User Preferences. To do this, double click on the Voice E-Mail 4.0 icon on your desktop. From the File menu, select User Preferences. This will bring up the User Preferences you entered at the time of installation. Please verify that you have entered your full Internet email address correctly (eg. johndoe@aol.com). If your address is not entered correctly in this field, your mail will be undeliverable.

    Please try this - log onto your ISP, connect to your web browser, minimize your ISP, double click on the Voice E-Mail 4.0 icon, select create, type in an e-mail address and subject, and then record and send your voice e-mail.

    If that didn’t work, please make sure you have the latest version of Voice E-Mail.  The latest version is 4.0.9, build #8 created on 5/18/99.   To check your version, please double click on the Voice E-Mail icon on your desktop, click help and then about.  Toward the middle it should indicate the version and build number.

    If you don't have the most recent version, please Click here.  This will take you to the updates page.

  4. 20010.

    The 20010 error generally means that the graphic file you are trying to use in the Voice E-Mail thumbnail viewer is too large in size, corrupted, or not a file type supported by the software. The Voice E-Mail Viewer supports the following image file formats:

    Bitmap Image Files (*.BMP)

    JPEG Image Files (*.JPG)

    PCX Image Files (*.PCX)

    WMF Image Files (*.WMF)

  5. Vemcreat.

    This error generally occurs when you double click on the create button. Please try to create another voice e-mail by single clicking the create button.

    Please try this - log onto your ISP, open your web browser (make sure you can browse the Internet), minimize your web browser, double click on the Voice E-Mail 4.0 icon, single click on create, type in an e-mail address and subject, and then record and send your voice e-mail. Click here if this does not work

  7. When I try to open Voice E-Mail, a message tells me that my "oleaut32.dll file is out of date." What should I do?

Please reinstall your Voice E-Mail software.

Close down Voice E-Mail if it is open.  Then, go to Start > Settings > Control Panel > Add/Remove Programs and remove Voice E-Mail.  When this is done, restart your computer.

When you're back up, find your VEMSETUPFULL.EXE file and double click on it to run the installation again.  This should clear up the problem.

  1. When I try to open Voice E-Mail, I receive "msinet.ocx or one of its dependencies not correctly registered"?

It appears that your file has gotten corrupted during the install. Or you may have an older version. You'll need the most updated version. In order to correct this problem, close all opened programs. Please rename the MSINET.OCX file in your C:\Windows\System directory  to msinet.hld and then replace it with this one: (MSINET.OCX). You may need to reboot your computer (shut it down and then restart it) for these changes to take effect.

  1. When I try to send a Voice E-Mail message, I get an "EMSMTP.dll" error.  What should I do?

There is currently an incompatibility between the version of the EMSMTP.DLL file that is used by BonziBUDDY and the one that is used by Voice E-Mail.  We are in the process of fixing this problem.

While we work to fix this incompatibility, if you would like to use Voice E-Mail, please go to Start > Settings > Control Panel > Add/Remove Programs and remove your BonziBUDDY.  Once BonziBUDDY is removed, go to Start > Find > Files and Folders and search your C: drive for an EMSMTP.DLL file.  When the file is found, right click on the file name and choose Delete.  Once the file is deleted run the Voice E-Mail installation again.  If you need to download Voice E-Mail again, please click here.
