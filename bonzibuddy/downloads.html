BonziBUDDY downloads

Updated October 13, 2026 · Unofficial work by Arthur Tube

The Bonzi.com continuation uses the original recovered 2004 pages and images. These instructions describe my update and tools.

Unofficial BonziBUDDY update

Download the unofficial update ZIP
  1. Extract the ZIP into a separate writable folder.
  2. Close any running BonziBUDDY copy.
  3. Open the package folder and start BonziBDY-4.1.0.10.exe. Keep its supporting files together.

This is an unofficial package, separate from Bonzi Software. The original program’s credits remain. Text and website-link changes do not restore registration, email, BonziWorld, or other retired servers. This update has not been certified free of the original program’s unwanted behavior; use an isolated virtual machine for testing.

EXE Text Customizer

Download the updated EXE Customizer

Export recognized text, edit the TXT, validate changes, and create a separate EXE with a backup. The capacity fix can restore known original string space when it is still unused. It keeps bounds checks and rejects edits that would overwrite occupied data.

  1. Extract the tool and run START_CUSTOMIZER.bat with Python 3 installed.
  2. Select the exact EXE you want to edit. Use 1 to find its TXT, then 2 to edit it.
  3. Keep all IDs. Use 3 to validate, then 4 to create the edited EXE.

Jokes, facts, personality & songs

Download the NBD Customizer

This separate tool edits the data files. It exports readable TXT, validates records, and applies changes with backups.

Open the site in your browser

Download the default-browser launcher

Run OPEN_BONZI_IN_DEFAULT_BROWSER.bat. Windows opens the site in your selected default browser, such as Edge, Chrome, or Firefox. It opens a separate browser; it does not replace BonziBUDDY’s internal Internet Explorer component.
