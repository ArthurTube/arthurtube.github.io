Downloading

  1. How do I remove/uninstall the free version of BonziBUDDY?

BonziBUDDY is easily removed following these instructions:

  • Click on Bonzi and and click on "Goodbye" to close him.
  • Go to Start > Programs > BonziBUDDY > Uninstall BonziBUDDY Bargain Hunting Tool and allow the uninstall program to finish. If this option is not listed in your BonziBUDDY folder, move on to the next step.
  • Go to Start > Programs > BonziBUDDY > Uninstall BonziBUDDY and allow the uninstall program to complete.
  • Restart your computer.

You may want to reset your home page after you uninstall your BonziBUDDY.  You can do this in Internet Explorer.  Just click on the Tools menu, select Internet Options, and go to the General tab to type in the location (URL) of a new home page.

The BonziBUDDY Web Compass is a free feature that works independently of BonziBUDDY.  If you would like to keep the Web Compass for an easy way to find links related to the web site you're browsing, you are welcome to leave it installed.  Removing BonziBUDDY will not affect the Web Compass.  To remove the Web Compass, open Start > Settings > Control Panel > Add/Remove Programs, highlight the BonziBUDDY Web Compass, and click on the Add/Remove button.

Most of all, thank you for trying BonziBUDDY!  Check back soon for new and exciting features!

  1. I can't remove BonziBUDDY using the instructions on your web site.

    If you are unable to remove BonziBUDDY using the instructions above, your initial installation of the program was not fully successful.  It may also be that a key file was deleted that the uninstall program needs in order to process the uninstall.

    If this is happening to you, please download and install Bonzi again to fix the uninstall feature.  There are too many individual settings and files involved in the BonziBUDDY program to remove all of them manually, so reinstalling to fix the uninstall program is your quickest and safest course of action.

    There is no need to delete any files first.  All you need to do is visit http://www.bonzi.com/freebuddy/bonzibuddyfree.asp and download the BonziBUDDY files again.  This will be a fast process if you already have most of the files installed, since the install will only download and install the files you don't have or ones that have been updated since your last download or update.

    Once you have successfully run the install of BonziBUDDY again, just follow the instructions in #1 above to uninstall BonziBUDDY.

  2. I still have a BonziBUDDY folder on my computer after removing BonziBUDDY.

When BonziBUDDY is uninstalled, there are a few small files left in your BonziBUDDY directory that will remind Bonzi what your settings and preferences are should you ever decide to install him again.  They are very small and will not harm your computer in any way, but it is safe to delete this folder if BonziBUDDY is already removed from your system.

  1. How do I remove the BonziBUDDY Web Compass?

The BonziBUDDY Web Compass is a free feature and is independent of BonziBUDDY, so you may keep it on your Internet Explorer toolbar if you would like. It does not slow down your browsing speed. If you want to remove it, just go to Start > Settings > Control Panel > Add/Remove Programs and uninstall the BonziBUDDY Web Compass from there.
