  1. When I try to use InternetBOOST with AOL 5.0, my InternetBOOST settings are changed.

    To correct this situation, you will need to disable the AOL dial-up adapter in your Windows Device Manager. To do this, go START> SETTINGS> CONTROL PANEL. Double click on the SYSTEM icon to bring up the System Properties window. Click on the DEVICE MANAGER tab, then double click on Network Adapters. Select AOL DIAL-UP ADAPTER and click the Properties button. Check the box for ‘Disable in this hardware profile.’ Then click OK. Now please reboot your computer (shut it down and then restart it). Making this change will not effect your AOL connection in any way.

  2. I am unable to find or install the InternetBOOST setup file (NBSETUPFULL2001) I have downloaded.

    Please refer to these installation instructions to locate and install your InternetBOOST program:

    1) From your desktop, go to START > FIND > FILES OR FOLDERS, and in the Named field, type NBSETUPFULL2001.EXE and click on FIND NOW.

    2) Once the NBSETUPFULL2001.EXE file is found, run the file by double clicking the left mouse button on the file icon. If you have more than one NBSETUPFULL2001.EXE file on your system, please be sure to double-click on the most recently dated file. The installation program will guide you through the installation procedure.

  3. When I try to open InternetBOOST, a message tells me that my "oleaut32.dll file is out of date." What should I do?

    Please reboot your computer (shut it down and then restart it). That should take care of the problem. Please try to open InternetBOOST again.

  4. When I try to open InternetBOOST, I receive "msinet.ocx or one of its dependencies not correctly registered"?

    It appears that your file has gotten corrupted during the install. Or you may have an older version. You'll need the most updated version. In order to correct this problem, close all opened programs. Please rename the MSINET.OCX file in your C:\Windows\System directory  to msinet.hld and then replace it with this one: (MSINET.OCX). You may need to reboot your computer (shut it down and then restart it) for these changes to take effect.

  6. I am unable to set up InternetBOOST and run it. How do I know which settings are the best to use? How do I start InternetBOOST to apply the boost?

    After you install InternetBOOST, you'll see that the installation program has created a program group in your Windows Program Manager. You can find it under the Start button, in Programs icon group, then in the InternetBOOST icon group.

    To start InternetBOOST, simply double-click the InternetBOOST icon and select your Internet Connection Type and settings. For Windows 95/98, we recommend the following settings:

    Internet Connection Type: Dial-Up (MODEM)

    MTU: 576 Auto Detection: ON (checked)

    Black Hole Detection: OFF (unchecked)

    RWIN: Multiple 4

    TTL: 64 recommended

    As with any utility that makes modifications directly to the system registry, you only have to run the Apply Boost one time. It will always be working at those settings unless you change them.

  7. How do I know what settings to choose in InternetBOOST? How does it work?

    There are three specific problems with the way Windows currently defaults to certain TCP/IP settings. By changing these defaults, you can improve the performance, in some cases dramatically, of your Internet connection. For example:

    Under Windows 95, the default MTU value is 1500, which is the optimal for Ethernet networks, but not dial-up modems. That's because many hosts on the Internet are configured with an MTU of 576, which causes size 1500 packets to be fragmented. This is not typically an issue with Windows NT since it uses what is called PMTU discovery, a process where it automatically determines the best segment size of each connection that is established. Although you can explicitly set the MTU value for Windows NT, in some cases doing so can actually hurt performance instead of improving it.

    The default Windows RWIN value is 8192, which is not evenly divisible by the default MSS (Maximum Segment Size) value of 1460 (the MSS value is the MTU minus 40). This means that as the receive buffer fills, it cannot store a complete packet, forcing that packet to be resent (sometimes again and again). Like MTU, this value is dynamic under Windows NT.

    And finally, the Windows default TTL value of 32 is appropriate for local networks, but it is insufficient for the Internet. The Time to Live, or TTL, is a field in the IP header which indicates how long a packet should be allowed to survive before it is discarded. TTL essentially determines the maximum number of hops permitted. The Windows default TTL value is 32, which specifies that the maximum number of routers that a packet may be forwarded through on to its destination be 32 or less. However, with the rapid expansion of the Internet and the increasing number of sites that a packet must be routed through, this is worth changing to a larger setting of 64 or higher.

  8. What's the best value to set these parameters to?

    Each system is different, so there are no hard and fast rules. However, good default values that all systems should be able to use are an MTU of 576 (which means an MSS of 536), an RWIN of 2144 (Multiple x 4) or 4288 (Multiple x 8) and a TTL of 64. You may want to experiment with these values to see which gives you optimal performance, based on your service provider, modem speed, etc.

  9. I don’t notice any change in the speed of my dialup connection or my modem speed.

    InternetBOOST doesn’t necessarily make your modem connect at a faster speed. The speed indicator that your modem gives you is actually deceptive. For example, if you connect at 28,800, that is the optimal speed that your modem and the Service Provider’s modem negotiated. But that doesn’t mean that the packets of information being sent between those modems is traveling at that speed. In fact, they are probably sending and receiving information at a speed that varies depending on the packet sizes (based on your MTU & RWIN settings) and on how busy the Service Provider’s server is at that time.

    Another example is the 56k modems. Although they are meant to connect at 56k, most of the phone lines in the world can’t handle transmitting information at that speed. So even though it may say it is connected at 56k, it is probably really communicating at a lesser speed.

    InternetBOOST helps your modem & computer work more efficiently and effectively. You may have to try different settings to find what works for your system, but you can test it by timing the download time of a particular site or by sending a particular file via e-mail at different settings.  If you’re not experiencing an increase in speed try adjusting the RWIN to multiple 6, 8 or 10.  Although we recommend multiple 4, several of our customers have told us that their system performs better on one of the other multiples. Since each system is different, it is hard to tell what settings will be best for yours.  You should find one that results in optimal performance.  You will not necessarily see a change in your connection speed.  Rather, you should see an enhancement of your existing connection, resulting in increased speed in browsing the Internet. You can test it by timing the download time of a particular site or a small file.

  10. I have Windows 98. What are the best settings for my operating system?

    The areas most important to Windows 98 are the RWIN and TTL areas. In the TTL section, please be sure that you have selected 64, and then select Multiple in the RWIN area and try the different choices there until you feel you are getting the optimum speed from your system.  You must "apply boost" and restart your computer to test each setting.  Without restarting, your computer continues to use the current values.

  11. Will InternetBOOST work with Windows 2000 or Windows ME?

InternetBOOST will not work with Windows 2000 or Windows ME systems.
