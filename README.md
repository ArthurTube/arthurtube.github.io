# ArthurTube website

A self-contained personal homepage inspired by the playful navigation and classic-web spirit of the supplied reference. Original ArthurTube design; no images, scripts, or assets from Alex Parr's site are required.

## Preview

Open `index.html` in your browser. All styles and scripts are included in that file. No installation or build step is needed.

## Publish at https://arthurtube.github.io/

1. Sign in to the GitHub account named `ArthurTube`.
2. Create a public repository named exactly `arthurtube.github.io` (or open it if it already exists).
3. Upload `index.html`, `404.html`, `.nojekyll`, and `BonziBuddy-Customizer.zip` to the repository's top level. Do not upload the ZIP itself or put the files inside another folder. The README is optional.
4. Commit the files to `main`.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select **main**, then **/(root)**, and click **Save**.
8. Wait for the deployment to finish, then open the site URL shown in Pages settings.

If your GitHub username differs, use `YOUR-USERNAME.github.io` instead. For a project repository, the same homepage works under `https://YOUR-USERNAME.github.io/REPOSITORY/`.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
