Icons in the System Tray

When CyberBuddy is running, the CyberBuddy icon in the System tray will tell you something about the current condition of the CyberBuddy Program.


You will notice that there are usually two icons in the system tray when CyberBuddy is running. One is the CyberBuddy Icon as shown above. The other, is the icon for the Agent Character that is currently loaded.
