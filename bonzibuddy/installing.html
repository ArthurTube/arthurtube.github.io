Installing

  1. I have successfully downloaded the file VEMSETUPFULL to my computer.  But how do I install it?

    Simply run VEMSETUPFULL. The installation screen will pop-up and guide you through the rest of the installation. To "run" VEMSETUPFULL, use your "Windows Explorer" or "File Manager" to double-click folders until you open the folder that contains VEMSETUPFULL. Then simply double-click on VEMSETUPFULL to run it. The installation screen will pop-up and guide you through the rest of the installation.

  2. I can't find the file on my computer. I think I successfully downloaded it, but I don't know where it is. How can I find it?

    Click the "Start" button, point to "Find," and then click "Files or Folders." In the "Named" box, type the file's name (for example, VEMSETUPFULL ). Click "Find Now" to find the file. Then simply double-click on the file to run it. The installation screen will pop-up and guide you through the rest of the installation.

  3. When I try to install the program, I get the error "corrupt installation file" or "Win32"?

    The error "corrupt installation file" or "Win32" is usually caused by an incomplete download. What sometimes happens when there is a slow download is that your computer thinks the download is done because it hasn't received any new information for a while. In fact it isn't, but since you don't have the entire program, when you try to run it, it will fail with the above error. The solution is to delete the incomplete or corrupt file and then download the program again.

  4. I can't get Voice E-Mail to work with the BETA version of AOL, IE, Netscape, CompuServe, etc.

    Please check the System Requirements for the version of Voice E-Mail you are trying to install. If it says Voice E-Mail is supposed to work with the BETA version you are running, contact Technical Support. Note: Most pre-release versions are not supported because they are constantly changing -- time after time -- often on a daily basis -- from one version to the next. However, final release versions will be supported soon after they become available.
